📺 Twitch VOD Sync Player

⚙️ Configuration

VOD ID: The numeric ID from the Twitch VOD URL. Example: twitch.tv/videos/2345678901 → enter 2345678901
Offset: Time adjustment to sync VODs. Use 0 for the reference VOD. Positive if this VOD starts later, negative (prefix with -) if it starts earlier.
Duration: How long to watch this VOD before auto-swapping. Leave empty to use default. Use 0 to skip this VOD in rotation.
Label: A friendly name to identify each stream (e.g., streamer name).
⏱️ Supported Time Formats (for Offset, Duration, Start Time):
90 = 90 seconds  |  1:30 = 1 min 30 sec  |  1:25:03 = 1 hr 25 min 3 sec  |  -45 = negative 45 sec  |  -1:30:00 = negative 1 hr 30 min
